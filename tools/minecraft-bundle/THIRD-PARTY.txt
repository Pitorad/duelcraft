DuelCraft ships this copy of Minecraft's launcher setup so Melty can start Minecraft with DuelCraft in one click.
It contains no Minecraft and no Yu-Gi-Oh! Master Duel files: Prism Launcher downloads Minecraft after you sign in
with a Microsoft account that owns Minecraft: Java Edition, and DuelCraft reads the cards (names, text, stats, art)
from your own Yu-Gi-Oh! Master Duel install (free on Steam) each time you play.
