DuelCraft ships this copy of Minecraft's launcher setup so Melty can start Minecraft with DuelCraft in one click.
It contains no Minecraft, Yu-Gi-Oh! Master Duel or Yu-Gi-Oh! Duel Links files: Prism Launcher downloads Minecraft
after you sign in with a Microsoft account that owns Minecraft: Java Edition, DuelCraft reads the cards (names, text,
stats, art) from your own Yu-Gi-Oh! Master Duel install and the characters' faces and voice lines from your own
Yu-Gi-Oh! Duel Links install (both free on Steam) each time you play.
